## About

I build software that ships: native desktop and mobile apps on the Microsoft Store and F-Droid, the FastAPI backends behind them, and systems projects in distributed storage and private networking.

- **Certified** Fortinet Associate in Cybersecurity and OCI Foundations Associate.
